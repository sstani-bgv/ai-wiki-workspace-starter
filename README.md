# Второй мозг для ИИ-агента

Личная система памяти в обычных Markdown-файлах: профиль пользователя, связанная wiki и реестр проектов. Агент задаёт несколько вопросов на русском и создаёт систему под вас.

## Установка одной ссылкой

Отправьте агенту эту ссылку и попросите настроить систему:

https://github.com/sstani-bgv/ai-wiki-workspace-starter

Для однозначного запуска можно скопировать сообщение целиком:

```text
Настрой мне систему памяти по этому репозиторию:
https://github.com/sstani-bgv/ai-wiki-workspace-starter

Прочитай SETUP.md, задай вопросы на русском и создай систему в моей рабочей папке.
```

Нужен агент, который умеет читать и создавать локальные файлы. Если он не может открыть GitHub, скачайте репозиторий и попросите прочитать `SETUP.md`. Агент в чате без доступа к файлам сможет подготовить содержимое, но не установит систему на компьютер.

## Что получится

```text
ваша-рабочая-папка/
├── AGENTS.md                 # общие инструкции агенту
├── CLAUDE.md                 # ссылка на AGENTS.md
├── USER.md                   # ваш профиль и предпочтения
├── wiki/
│   ├── index.md              # карта знаний
│   ├── SCHEMA.md             # правила ведения wiki
│   ├── inbox.md              # ещё не обработанные материалы
│   ├── log.md                # история изменений
│   ├── pages/                # связанные страницы по темам
│   │   └── workspace/        # начальная тема о вашей системе
│   ├── raw/                  # источники и их происхождение
│   └── attachments/          # изображения и другие вложения
├── projects/
│   ├── index.md              # реестр проектов
│   ├── project-template.md   # шаблон карточки проекта
│   └── _templates/           # инструкции для будущего проекта
├── skills/                   # ваши повторяемые процедуры
└── outputs/                  # готовые материалы в Marp Markdown
```

Файл профиля называется `USER.md` (верхний регистр). Он хранится один раз в корне, wiki ссылается на него.

Начальная wiki объясняет устройство системы. Агент добавит ваши цели и темы только по вашим ответам: чужих биографий, клиентов и выдуманных знаний в шаблоне нет.

Каждый будущий проект — отдельный репозиторий в `projects/<id>/` со своими инструкциями. Внешняя система хранит только карточки и общие знания. При установке существующие проекты не анализируются, не переносятся и не изменяются.

## Как пользоваться

- «Запомни это решение в wiki и укажи источник».
- «Разбери этот материал: сохрани источник в raw, а выводы свяжи с нужными страницами».
- «Что мы уже знаем по этой теме? Покажи страницы и источники».
- «Проверь wiki на противоречия, устаревшие факты и сломанные ссылки».
- «Создай новый проект по шаблонам в projects/_templates».

Можно открыть `wiki/` в любом Markdown-редакторе, включая Obsidian. База данных, векторный поиск, плагины и подписки для структуры памяти не нужны. Использование самого агента зависит от выбранного сервиса.

## Что делает установщик

1. Уточняет путь к рабочей папке.
2. Коротко спрашивает о вас, задачах и стиле работы.
3. Копирует недостающие шаблоны и персонализирует новые файлы.
4. Проверяет ссылки и показывает созданную систему.

Существующие файлы сохраняются; для их изменения агент сначала показывает конкретное предложение. Git и публикация личного воркспейса — отдельные действия по вашему запросу. Ссылка на этот публичный шаблон не публикует вашу личную wiki.

Инструкции установки: [SETUP.md](SETUP.md). Проверка из нового чата: [VERIFY-WORKSPACE.md](prompts/VERIFY-WORKSPACE.md). Шаблоны: [templates/workspace](templates/workspace/).
