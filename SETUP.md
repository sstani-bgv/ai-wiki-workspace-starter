# Установка системы памяти

Это основной вход для агента. Если пользователь просто прислал ссылку на этот
репозиторий с просьбой настроить память, запусти описанную ниже установку.

## Результат

Отдельная рабочая папка с `USER.md`, инструкциями `AGENTS.md`/`CLAUDE.md`, wiki и
шаблонами будущих проектов. Установка работает через Markdown-инструкции;
специальный установщик, другой агент, плагины и база данных не нужны.

## Общие правила

- Веди разговор на русском, если пользователь не попросил другой язык.
- Используй уже сказанное пользователем. Не задавай повторных вопросов.
- Задавай вопросы небольшими блоками; достаточно пути и одного короткого интервью.
- Можно пропустить любой личный вопрос. Не делай внешний поиск о пользователе.
- Не читай секреты, аккаунты, всю историю пользователя или код проектов.
- Не меняй, не клонируй и не анализируй существующие проекты при установке.
- Копируй только недостающие файлы. Не перезаписывай существующие файлы или симлинки.
- Если файл существует, прочитай только нужный файл, покажи конкретную предлагаемую
  правку и дождись согласия на неё. Отказ не мешает установить остальные части.
- Не создавай Git-репозиторий, коммиты, remote и публикацию без запроса пользователя.
- Не устанавливай инструменты и не меняй глобальные настройки агента.
- Не выдумывай факты. Пиши «Не указано», когда ответа нет.

## Подготовка

Если пакет ещё не доступен локально, скачай или склонируй его в уникальную временную
папку системного temp (на macOS/Linux — `/tmp`). Запомни точный путь. Не используй
папку пакета как личный воркспейс; не копируй `.git`, remote и историю шаблона.

Если пользователь уже скачал пакет в папку, считай её источником шаблонов и уточни
отдельную папку для личной системы. Не перемещай и не удаляй его файлы автоматически.
Если доступа к файлам нет, честно сообщи об этом до установки.

## Этапы

Читай инструкции по одному этапу и выполняй их последовательно:

1. [Выбрать папку](prompts/setup/01-WORKSPACE.md).
2. [Короткое интервью](prompts/setup/02-INTERVIEW.md).
3. [Создать и персонализировать систему](prompts/setup/03-INSTALL.md).
4. [Проверить и передать пользователю](prompts/setup/04-VERIFY.md).

Не запускай интервью из нового агента: общение ведёт текущий агент.
Для независимой проверки файлов можно использовать помощника без личной истории,
если среда поддерживает такую возможность. Иначе проверь самостоятельно.

## Когда установка завершена

В выбранной папке есть профиль, рабочие инструкции, карта wiki, схема, журнал,
inbox, начальная тема, raw, attachments и реестр с шаблонами проектов. Все локальные
ссылки работают, новые персонализированные страницы не содержат незаполненных
полей, а источники выводов указаны. Существующие проекты не изменены.

Сообщи, что проверено сейчас, и отдельно дай проверку из нового чата. Не объявляй
проверку из нового чата выполненной, если она не запускалась. Git не обязателен.
