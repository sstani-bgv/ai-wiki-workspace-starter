# Инструкции для агента

Этот репозиторий — установочный пакет, а не личный воркспейс пользователя.

Если пользователь прислал ссылку и хочет создать систему памяти, начни с `SETUP.md`.
Задавай вопросы и объясняй настройку на русском. Устанавливай шаблоны из
`templates/workspace/` в отдельную папку пользователя; не персонализируй этот пакет.

При разработке пакета сохраняй универсальность инструкций: без абсолютных путей
автора, личных проектов, аккаунтов, биографий и секретов. Инструкции установки не
должны изменять существующие дочерние проекты. Проверь локальные Markdown-ссылки,
согласованность маршрутов и отдельно сохрани проверку из нового чата.
