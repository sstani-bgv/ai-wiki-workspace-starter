# Реестр проектов

Каждый проект — независимый репозиторий со своей историей и `AGENTS.md`.
Внешний воркспейс хранит карточки `projects/*.md`, а папки `projects/<id>/`
исключены из его Git. Шаблоны `_templates/` остаются в Git внешнего воркспейса.

## Проекты

Пока нет зарегистрированных проектов. Установка не меняет существующие проекты.

При подключении по запросу пользователя добавь строку с названием, кратким
назначением и ссылкой на карточку. Путь и remote записывай по проверенным данным;
не выдавай пример или неизвестное за реальный проект.

## Шаблоны

- [Карточка проекта](project-template.md).
- [Инструкции нового проекта](_templates/README.md).

Если код ещё не скачан, клонирование — отдельная задача пользователя, не часть
установки памяти. Не выбирай remote и не создавай проект по догадке.
