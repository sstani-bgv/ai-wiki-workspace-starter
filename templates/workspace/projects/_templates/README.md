# Шаблоны нового проекта

Эти файлы — общие инструкции, адаптированные из системы автора. Они не содержат
его аккаунтов, клиентов или личных задач.

По запросу на новый проект:

1. Создай отдельный репозиторий в `projects/<id>/`.
2. Скопируй [AGENTS.md](AGENTS.md) в его корень и заполни назначение и ID.
3. Скопируй [CLAUDE.md](CLAUDE.md) в его корень.
4. Заполни [карточку](../project-template.md) и добавь её в [реестр](../index.md).
5. Проверь путь к общей [wiki](../../wiki/index.md) и отсутствие проекта в Git
   внешнего воркспейса. В дочернем проекте путь — `../../wiki/index.md`.

Для существующего проекта предложи точечное объединение инструкций только по
отдельному запросу. Для командного репозитория по умолчанию достаточно карточки;
не вноси личные маршруты памяти в общие инструкции команды.
