# Вложения

Сохраняй материалы в `attachments/<topic-or-source>/`: изображения, выдержки,
транскрипты и данные, необходимые для проверки источника.

Укажи происхождение и относительные ссылки в соответствующей записи
[raw](../raw/README.md). Из страницы выводов ссылайся на источник; добавляй прямую
ссылку на вложение, когда оно помогает понять вывод.

Тяжёлые аудио и видео исключены из Git по умолчанию. Их отсутствие в клоне нужно
явно отмечать. Не сохраняй здесь секреты и приватные данные аккаунтов.
