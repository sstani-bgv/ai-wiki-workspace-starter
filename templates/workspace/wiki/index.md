# Карта знаний

Здесь хранятся долговременные факты, решения и связи.
При чтении начни с этой карты и следуй только ссылкам по текущей задаче.

Для записи используй узкий процесс: прочитай [схему](SCHEMA.md), сохрани источник,
обнови нужные страницы и хабы, сохрани происхождение выводов и добавь запись в
[журнал](log.md). Если доступен помощник с чистым контекстом, дай ему только новые
данные, источники и область обновления. Основной агент проверяет предложенный diff.
Без помощника выполняй эти действия самостоятельно. Запись должна соответствовать
запросу пользователя; неподтверждённое оставляй в inbox.
